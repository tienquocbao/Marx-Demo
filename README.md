# Phố Trao Đổi Deluxe

Mini game giáo dục Kinh tế chính trị Mác – Lênin: so sánh hình thức hàng đổi hàng (H–H) và hàng–tiền–hàng (H–T–H).

## Chạy thử

Mở `index.html` trong trình duyệt Chrome hoặc Edge. Không cần máy chủ hay kết nối mạng.

## Triển khai GitHub Pages

1. Tạo repository công khai, ví dụ `pho-trao-doi`.
2. Tải `index.html` vào **thư mục gốc** (root) của repository trên nhánh `main`.
3. Vào **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, chọn **main** và **/(root)**, sau đó **Save**.
4. Khi xuất bản hoàn tất, mở `https://USERNAME.github.io/pho-trao-doi/` (đổi USERNAME thành username GitHub của bạn).

Các giá trị trong trò chơi là giả định dành cho giáo dục, không phải giao dịch thực tế.
